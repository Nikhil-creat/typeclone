Core capabilities

Dual-Engine Extraction

Structural PDF parsing (PyMuPDF) for vector text; OCR + layout analysis (PaddleOCR/OpenCV) for scans and PNGs — unified into one typography schema.

Style Cloning

Weight, italic slant, proportional scaling, tracking, and exact RGB color sampling, reproduced on redraw.

Content-Aware Erase

Vector redaction removes glyph outlines cleanly; raster inpainting (Telea) restores background texture before new ink is drawn.

Font Similarity Matching

Visual-metrics embedding (x-height, stroke density, slant) finds the closest available font when an exact family can't be resolved.

Live Collaboration

WebSocket channel per document streams render progress, undo/redo events, and peer cursor state to every connected client.

Non-Destructive History

Every edit is a diff in an undo/redo ledger — nothing is baked into the source document until export.
